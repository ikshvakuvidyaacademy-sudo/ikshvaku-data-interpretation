## 📌 Overview

**`ikshvaku-data-interpretation`** is the official **Data Interpretation & Data Sufficiency Question Bank** for the **Ikshvaku Aptitude Arena** by **Ikshvaku Vidya Academy**.

It contains **500,000+ verified DI questions** across 17 standardized competitive examination topics.

---

## 🎲 Random Exam Generator (`scripts/generate_random_exam.py`)

Selects strictly random, non-repeating questions with dynamic option shuffling:

```bash
python scripts/generate_random_exam.py --count 25
```
